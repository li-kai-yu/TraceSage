# 03 包结构与命名规范

## 1. 完整包结构

### 1.1 业务服务（tracesage-system / tracesage-insight）

```
com.tracesage.{service}
├── {Service}Application.java            启动类
├── interfaces/                          用户接口层
│   ├── controller/                       XxxController
│   ├── dto/                              XxxDTO、XxxQuery
│   ├── vo/                               XxxVO
│   └── assembler/                        XxxAssembler（DTO/VO < > 领域对象）
├── application/                         应用层
│   ├── service/                          XxxAppService
│   ├── command/                          XxxCommand
│   ├── query/                            XxxQuery
│   ├── dto/                              XxxResultDTO
│   └── assembler/                        XxxAppAssembler
├── domain/                              领域层（不依赖任何框架）
│   ├── model/
│   │   ├── entity/                       Xxx、XxxId
│   │   ├── valueobject/                  XxxValue
│   │   ├── aggregate/                    聚合根 Xxx
│   │   └── enums/                        XxxStatus、XxxType
│   ├── service/                          XxxDomainService
│   ├── repository/                       XxxRepository（接口）
│   ├── gateway/                          XxxGateway（外部系统防腐接口）
│   └── event/                            XxxCreatedEvent
└── infrastructure/                      基础设施层
    ├── persistence/
    │   ├── mapper/                       XxxMapper（继承 BaseMapper）
    │   ├── po/                           XxxPO
    │   ├── converter/                    XxxConverter（MapStruct）
    │   └── repository/                   XxxRepositoryImpl
    ├── config/                           XxxConfig
    ├── mq/                               XxxProducer、XxxConsumer
    ├── es/                               XxxEsRepository
    ├── cache/                            XxxCache
    └── external/                         XxxClient（Feign / 三方适配）
```

资源目录：

```
src/main/resources/
├── application.yaml                     主配置
├── mapper/                              MyBatis XML（复杂 SQL 才写 XML）
└── META-INF/spring/                     自动装配（仅公共模块需要）
```

## 2. 命名规范

### 2.1 类名后缀（必须遵守）

| 后缀 | 所属层 | 示例 |
| --- | --- | --- |
| `Controller` | interfaces | `TraceQueryController` |
| `DTO` | interfaces | `TraceQueryDTO` |
| `VO` | interfaces | `TraceDetailVO` |
| `Assembler` | interfaces / application | `TraceAssembler` |
| `AppService` | application | `TraceIngestAppService` |
| `Command` | application | `CreateFaultCaseCommand` |
| `Query` | application | `TraceSearchQuery` |
| `DomainService` | domain | `TraceTopologyDomainService` |
| `Repository` | domain（接口） | `TraceRepository` |
| `RepositoryImpl` | infrastructure | `TraceRepositoryImpl` |
| `Gateway` | domain（外部接口） | `LlmGateway` |
| `PO` | infrastructure | `TraceSpanPO` |
| `Mapper` | infrastructure | `TraceSpanMapper` |
| `Converter` | infrastructure | `TraceSpanConverter` |
| `Producer` / `Consumer` | infrastructure | `TraceProducer` / `TraceConsumer` |
| `Config` | 任意层 | `RedisConfig` |
| `Event` | domain | `TraceIngestedEvent` |
| `Exception` | common-core | `BizException` |

### 2.2 命名基本规则

- 包名：**全小写**，单词间直接连接，不用复数、不用下划线：`valueobject`、`persistence`。
- 类名：大驼峰；方法/变量：小驼峰；常量：全大写下划线。
- **禁止拼音、禁止缩写**：`getUserInfo` 而不是 `getYhxx`；`TraceId` 而不是 `Tid`。
- 布尔字段不用 `is` 前缀（除非 boolean 类型），如 `deleted`、`enabled`。
- 集合字段用复数：`spans`、`tags`。

### 2.3 方法命名

| 场景 | 前缀 | 示例 |
| --- | --- | --- |
| 查询单个 | `find` / `get` | `findById`、`getCurrentUser` |
| 查询列表 | `list` / `search` | `listByTraceId`、`searchPage` |
| 统计 | `count` / `statistics` | `countByStatus` |
| 新增 | `create` / `save` | `createFaultCase` |
| 修改 | `update` / `modify` | `updateStatus` |
| 删除 | `delete` / `remove` | `deleteById` |
| 业务动作 | 动词 | `submit`、`approve`、`ingest`、`analyze` |

- 领域实体的行为方法用业务语言：`trace.markFailed(reason)`，而不是 `trace.setStatus(FAILED)`。
- 仓储接口方法**不带 SQL 语义**：`findByTraceId` ✅，`selectOneByTraceId` ❌。

## 3. Git 与 Maven 坐标

- groupId：`com.tracesage`
- artifactId：`tracesage-{模块名}`，全小写短横线分隔
- 版本：统一由根 pom 的 `<revision>` 控制，子模块不单独写版本
